### 5.1 Stage-2 design
- **Label:** among eventful bars at h18, `y2 = 1` if `lup_18` first, else `0`
  (≈53/47, balanced by construction).
- **Model:** same LSTM trunk, single sigmoid head, balanced BCE.
- **Small-data mitigation** (fold-0 ≈6.6 k sequences): use an **any-horizon
  union mask** (`OR over h ∈ {6..24}` → ~3–4 %), add dropout, 3-seed ensemble,
  early-stop on **val up-vs-dn AUC** (not AP).
- **Leak-free per fold:** train on fold-train eventful, early-stop on fold-val
  eventful, evaluate on fold-test eventful; purge `MAX_H` at both boundaries.
  Stage 2 never sees test.

### 5.2 Two-stage combined evaluation
- Stage 1: `event_score = P_up18 + P_dn18` → per-day τ (`rolling_triggers`) →
  triggers.
- Stage 2: `direction = sign(stage2_score)` on those triggers.
- **Direction-aware metrics only:** up-vs-dn AUC | eventful; DE; DC;
  market-neutral spread S; **net bps after 10 bp taker / 4 bp maker**. Do **not**
  rank on AP/lift (they pass on the volatility artifact).
- **Anti-double-dipping:** stage-2 trained on train/val only; combined PnL
  reported on test only; the same folds and purge as 009f.

## 9. Cross-reference — economic feasibility of H1/H2

*Added 2026-09-22 by a separate session; §1–§8 above are unmodified. Companion:
`runs/horizon_economics_and_next_ideas.md` (§1 required-accuracy arithmetic, §6
the measured cost curve). Nothing in this section changes the plan's design — it
changes the **thresholds**.*

### 9.1 What this plan needs, in accuracy terms

For a hold-to-horizon trade with symmetric payoff, `net = (2p − 1)·E|move| − F`,
so the accuracy required to break even is `p = (1 + F/E|move|)/2`. This plan's
own §2 measures `E|move| = 18.57 bp` on its stage-1 trigger set:

| fee route | F (round trip) | **p required** | ≈ AUC |
|---|---|---|---|
| full-maker | 4 bp | **0.608** | **0.65** |
| maker-in / taker-out | 7 bp | 0.688 | 0.76 |
| realistic maker with a stop | 9 bp | 0.742 | 0.82 |
| taker (what **H2** asks for) | 10 bp | **0.769** | **0.85** |

AUC↔accuracy uses the equal-variance Gaussian mapping (`AUC = Φ(d'/√2)`,
`accuracy = Φ(d'/2)`), which is the standard first-order translation for a
balanced binary target — good enough to set a threshold, not a precise claim.

### 9.2 The H1/H2 inconsistency

- **H1** asks for stage-2 AUC **> 0.55** ⇒ ≈ **53.5 %** accuracy.
- **H2** asks for **net taker > 0** ⇒ ≥ **76.9 %** accuracy.

**The gap is ~23 accuracy points.** H1 can pass while H2 fails by a wide margin,
and on the current evidence that is the expected outcome. This is structurally
the same result as runs 009d–f, where gate criterion B passed on the volatility
artifact while every economic criterion failed — the failure mode the plan's own
§5.2 warns about ("do not rank on AP/lift").

The plan's own combined number makes the size of the gap concrete: gross
**+0.90 bp** on an 18.57 bp trigger set implies a current accuracy of
`(0.90/18.57 + 1)/2 = ` **52.4 %**. H2 needs 76.9 %.

### 9.3 Recommended threshold change

Replace H1 with the economically required bar, and keep everything else:

- **H1 (revised):** stage-2 out-of-fold AUC **≥ 0.65** (≈ 61 % accuracy — the
  full-maker breakeven). Below that, no fee route on this trigger set is
  net-positive, so the run cannot produce a tradeable result regardless of what
  else passes.
- **H2:** unchanged, but report net at **4 / 7 / 9 / 10 bp** rather than taker
  only, so the result says *which* fee route it would need rather than just
  "fails".
- **Falsification branch:** widen from `AUC ≤ 0.52` to **`AUC < 0.65`** →
  direction is not learnable at a tradeable strength from the current bar
  features; close this ladder.

This keeps the experiment (the scientific question — *can a dedicated balanced
stage-2 model beat 0.47?* — is genuinely untested and worth answering) while
making it decisive in both directions.

### 9.4 Two caveats on the economics

1. **The 4 bp full-maker floor is not reachable while a stop exists.** The 009f
   sim correctly pays taker on every SL and time-stop (`btc_lstm.run.009f.ipynb`
   cell 16:58–65), so the honest round trip is 7–9 bp and the honest requirement
   is 0.69–0.74, not 0.61. The plan's `maker −3.10` figure assumes the
   unreachable 4 bp.
2. **Eventful bars are where adverse selection is worst.** Stage 1 selects the
   highest-volatility bars in the sample — precisely the bars on which a resting
   limit gets run over (`hit_f 4.4 % ≪ hit_m 18.0 %`). The ~5 bp selection cost
   measured in runs 008–011 applies *more* strongly to this trigger set, not
   less, so the effective maker cost is toward the top of the 7–9 bp range.
